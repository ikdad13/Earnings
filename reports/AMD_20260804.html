Prepared Remarks — 한글 해석

영어 요약이 아니라 경영진 발언의 의미를 한국어로 풀어서 썼습니다.

Lisa Su — 총괄 메시지: record quarter + AI adoption cycle 초기 국면

Lisa는 이번 분기를 “record revenue and profitability”라고 규정했다. 매출이 전년 대비 50% 증가했고, EPYC·Instinct·Ryzen·Embedded processors 전반의 채택 확대가 동시에 작동했다는 설명이다. 특히 Data Center가 전체 매출의 58%까지 올라왔다는 점을 강조했다. 1년 전에는 42%였기 때문에 AMD의 사업 구조가 PC/콘솔 경기보다 서버 CPU와 AI accelerator cycle에 훨씬 더 민감해졌다는 뜻이다. 투자적으로는 단순 매출 beat보다 mix shift가 중요하다.

Data Center CPU — EPYC 수요는 cloud와 enterprise 모두 강함

EPYC는 cloud와 enterprise sales가 각각 70% 이상 성장했고, 5분기 연속 record server CPU revenue를 기록했다. Hyperscaler는 내부 인프라와 public cloud instance 모두에서 EPYC 채택을 늘리고 있고, Turin은 글로벌 EPYC public cloud instance 1,600개+ 중 거의 1/3을 차지할 정도로 빠르게 확산 중이다. 기업 고객 쪽도 금융, 제조, 통신, 리테일, 기술기업의 대규모 deployment가 언급됐다. 즉 CPU 성장은 단일 hyperscaler pull-in이 아니라 cloud + enterprise broad-based demand로 설명했다.

Data Center AI — Helios/MI450 visibility가 2027 논리의 중심

Instinct 매출은 전년 대비 두 배 이상 늘었고, MI350 adoption은 AI labs, cloud providers, AI startups, national labs, sovereign AI deployment로 넓어졌다. Helios는 EPYC Venice CPU, MI450 GPU, Pensando networking, ROCm software를 묶은 rack-scale AI platform이다. AMD는 OpenAI·Meta의 multi-generation gigawatt-scale deployments 외에도 Anthropic의 최대 2GW MI450 Helios deployment, Microsoft Azure의 Helios at scale deployment를 언급했다. 핵심은 “initial shipments later this quarter, ramp through Q4 and into 2027”이다. Q3는 시작, Q4 step-up, 2027 본격 ramp다.

ROCm/software — 하드웨어만이 아니라 production deployment 준비가 핵심

ROCm은 production scale deployment에 필요한 performance, capabilities, developer experience를 갖춘 inflection point에 도달했다고 설명했다. 300만 개 이상의 모델이 AMD에서 out-of-the-box로 실행되고, ROCm open-source contributions가 10배 이상 늘었으며, ROCm.AI를 통해 Claude/Codex/Cursor 같은 coding agent로 Instinct용 코드 생성·포팅·최적화를 쉽게 만들겠다고 했다. 이는 “AMD GPU는 software가 약하다”는 시장 할인 요인을 줄이려는 메시지다.

CFO Jean Hu — 성장 강하지만 재고/CapEx/OpEx가 같이 늘어남

Jean은 Q2 매출 115억 달러, non-GAAP GM 56%, non-GAAP OP 31억 달러, FCF 16억 달러를 제시했다. 그러나 inventory가 약 85억 달러까지 증가했고, CapEx/PP&E가 8.08억 달러로 커졌다. 이는 강한 Data Center demand를 지원하기 위한 선투자이지만, 단기 FCF와 margin sensitivity를 높이는 요인이다. Q3 가이던스는 매출 130억 달러±3억 달러, non-GAAP GM 약 56%, OpEx 약 36.5억 달러로 제시됐다.

Q&A 전체 상세 정리

Q1. Tom O’Malley / Barclays

질문 의도 / 배경: GPU TAM 1.4T와 CPU TAM 220B의 성장축 중 2027년에 어느 쪽이 더 클지, 그리고 GPU ramp margin headwind를 CPU margin tailwind가 상쇄할 수 있는지 확인했다.

경영진 답변 상세: Lisa는 accelerator와 server CPU 모두 강하게 성장하지만, AI accelerator TAM이 더 크므로 Helios strategic customer ramp가 2027년 Data Center AI 매출을 크게 키울 것이라고 답했다. 동시에 server CPU도 2H26에 80%+ 성장, 2027년에도 중요한 성장축이라고 했다. Jean은 server CPU는 corporate gross margin에 accretive이고, Data Center AI는 gross margin이 corporate average보다 약간 낮을 수 있지만 revenue/gross profit dollars가 매우 크다고 설명했다. Embedded 회복도 2027 margin tailwind라고 덧붙였다.

톤 / 투자 함의 / 다음 체크포인트: 강한 자신감. GPU margin이 약간 낮다는 점은 인정했지만, “gross profit dollars”와 CPU/Embedded mix로 방어 가능하다는 논리. 체크포인트는 2027 mix와 MI450 초기 yield/margin.

Q2. Timothy Arcuri / UBS

질문 의도 / 배경: Q2→Q3 성장에서 CPU와 GPU 중 어느 쪽이 더 큰지, 그리고 AMD가 2030 TAM CAGR 40%보다 더 빠르게 성장할 수 있는지 물었다.

경영진 답변 상세: Lisa는 Q3와 Q4 모두 server CPU와 Data Center AI가 성장한다고 답했다. Q3 Data Center segment는 sequential double-digit growth이고, Q4에는 그보다 높아질 수 있다고 했다. Helios ramp는 Q3 말 시작, Q4에 더 커지고 Q1에 추가 step-up 후 2027년 내내 ramp하는 구조라고 설명했다. 두 번째 질문에는 전체 TAM이 40%+ 성장하는데 AMD는 각 segment에서 시장보다 빠르게 성장할 기회가 있으므로 회사 전체 매출도 40%보다 빠르게 성장하겠다고 말했다.

톤 / 투자 함의 / 다음 체크포인트: Q3 숫자보다 중요한 건 cadence. “Q3 start → Q4 step-up → Q1 further step-up → 2027 ramp”가 모델링 핵심이다.

Q3. Vivek Arya / BofA

질문 의도 / 배경: 2027년에 AMD가 몇 GW의 compute visibility를 갖고 있는지, GW당 매출이 $15B+인지, Helios의 높은 HBM 탑재가 memory cost inflation/margin risk를 키우는지 물었다.

경영진 답변 상세: Lisa는 구체 GW 숫자는 확정하지 않았지만 OpenAI, Meta, Anthropic anchor customers가 ramp 중이고, Data Center segment가 2027년에 100% 이상 성장할 것으로 본다고 답했다. Revenue per gigawatt는 “double-digit billions” range라고 재확인했다. HBM 질문에는 memory partners와 multi-year로 협업해 2027 delivery에 필요한 HBM allocation visibility가 좋다고 했다. 동시에 HBM 용량/대역폭은 큰 모델에서 TCO 우위이지만, workload별로 memory footprint를 조정할 수 있다고 설명했다.

톤 / 투자 함의 / 다음 체크포인트: 투자자에게 중요한 답은 두 개: GW당 매출은 double-digit billions 유지, HBM allocation은 visibility 있음. 그러나 memory cost inflation은 계속 risk이고 workload별 config 조정 가능성이 margin lever다.

Q4. Joshua Buchalter / TD Cowen

질문 의도 / 배경: Server CPU 2027 성장이 unit인지 ASP인지, 그리고 Helios가 initial forecast보다 앞선다는 말이 volume인지 yield인지 확인했다.

경영진 답변 상세: Lisa는 Q2 server CPU 성장에서 unit과 ASP가 모두 늘었지만 unit growth가 더 컸다고 말했다. ASP는 higher core count로 올라가며, 앞으로도 unit과 ASP 둘 다 성장할 것으로 봤다. 공급 측면에서는 wafers, backend capacity, substrates, components 전반을 증설 중이라고 했다. Helios가 forecast보다 앞선다는 말은 yield가 아니라 2027년 demand volume이 초기 기대보다 크다는 뜻이라고 명확히 했다. Yield는 highly complex product 특성상 ramp 초기 몇 분기 동안 개선될 것으로 봤다.

톤 / 투자 함의 / 다음 체크포인트: 수요 upside는 volume에서 왔다. 단 Helios complex product라 초기 yield/margin ramp는 반드시 추적해야 한다.

Q5. Aaron Rakers / Wells Fargo

질문 의도 / 배경: Server TAM 220B를 general purpose, agentic sandbox, AI head node로 나눴을 때 agentic AI server opportunity가 얼마나 큰지 물었다.

경영진 답변 상세: Lisa는 2030년 기준 agentic AI/sandbox server가 server TAM의 가장 큰 조각이 될 것으로 본다고 했다. 지금은 가장 작지만 가장 빠르게 성장하는 영역이라고 설명했다. Venice는 per-core performance, socket performance, memory/IO flexibility를 통해 general purpose, agentic AI, accelerator head node 모두를 대응하는 family라고 강조했다. Turin에서 Venice로 넘어가면 hyperscaler workload가 더 넓어진다고도 말했다.

톤 / 투자 함의 / 다음 체크포인트: CPU story가 단순 교체수요가 아니라 agentic workload라는 신규 수요로 확장. 서버 CPU TAM 재평가 논리.

Q6. Stacy Rasgon / Bernstein

질문 의도 / 배경: Q2 Data Center +107%인데 Q3 성장률이 낮아 보이는 상황에서 “acceleration”을 어떻게 해석해야 하는지, 2027 “more than” 표현이 얼마나 강한지 캐물었다.

경영진 답변 상세: Jean은 acceleration은 Q2 단일 분기 대비가 아니라 2H vs 1H 기준이라고 설명했다. Lisa는 server CPU +70% 이상도 강하지만, 전체 Data Center는 well over 100% 성장할 수 있고, 그 이유는 Data Center AI가 well over 100% 성장하기 때문이라고 답했다. “more”라는 표현에 대해 웃으면서도 훨씬 큰 upside 가능성을 열어두는 뉘앙스였다.

톤 / 투자 함의 / 다음 체크포인트: 가장 bullish한 Q&A. 2027 Data Center AI 모델 상향 여지를 의도적으로 남겼다.

Q7. James Schneider / Goldman Sachs

질문 의도 / 배경: 초기 MI400/Helios 고객 diversity와 고객 데이터센터 준비상태/전력/부지/셸이 목표 달성의 병목인지 질문했다.

경영진 답변 상세: Lisa는 OpenAI, Anthropic, Meta 같은 frontier model 회사들이 CSP/hyperscaler를 통해 consuming하며, gigawatt-scale이 아닌 regular-scale 고객도 많다고 답했다. Q4~Q1로 갈수록 고객 diversity가 좋아질 것으로 봤다. Data center readiness에 대해서는 목표 달성에 pause를 줄 만한 요인은 보이지 않는다고 했다. 다만 range는 있으며, capacity를 얼마나 빨리 bring on하느냐가 upside/downside를 결정한다고 설명했다. AMD는 silicon, CPU, GPU, networking, Helios components 전체 supply chain과 data center operator visibility를 같이 관리 중이라고 했다.

톤 / 투자 함의 / 다음 체크포인트: 데이터센터 전력/부지 readiness는 industry bottleneck이지만 AMD guidance 달성에는 자신감. Q4/Q1 고객 다변화가 확인 포인트.

Q8. C.J. Muse / Cantor

질문 의도 / 배경: 2027 Instinct 매출 $30B 가정이 맞는지, MI450/Helios gross margin이 2027년 초와 말에 어떻게 변할지 물었다.
